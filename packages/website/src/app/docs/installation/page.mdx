# Install from a reviewed revision

Use Node.js 24, pnpm 11, Git, and Chromium. The complete workspace was verified with Node 24.13.1 and pnpm 11.24.0. The server's lower engine minimum does not describe the browser and documentation build toolchain.

## Build the local artifacts

The Pinvelto implementation is on the **issue/23 integration branch** until separately accepted and merged. Obtain the maintainer's reviewed commit or ref and replace **PINVELTO_REF** below. Do not assume the default main branch contains this implementation.

~~~sh
git clone https://github.com/luxi78/vibe-annotations.git
cd vibe-annotations
git checkout PINVELTO_REF
pnpm install --frozen-lockfile
pnpm --filter pinvelto-extension build
npm install --global ./packages/server
pinvelto --version
~~~

The npm source is this checkout's local server directory. Installation links to this checkout, so retain its files and dependencies. It does not download a public Pinvelto or upstream product package. Dependency installation may use the normal package registry.

If global installation requires elevated permissions, use a writable user prefix with npm install --global --prefix PATH ./packages/server and add its executable directory to PATH. On Windows, use pinvelto.cmd if execution policy blocks the generated PowerShell wrapper.

## Load the extension

Open chrome://extensions, enable **Developer mode**, choose **Load unpacked**, and select **packages/extension/.output/chrome-mv3**. Pin the Pinvelto action. Load the production build, not .output-e2e; that directory belongs to controlled acceptance tests.

## Start and configure

~~~sh
pinvelto init --agent codex --non-interactive
pinvelto status
~~~

Init starts the local service and creates a new pinvelto MCP entry. Run pinvelto init --help for other agents and scopes. Existing entries are preserved, including another product's configuration. Reconnect or restart the coding agent afterward. The production endpoint is http://127.0.0.1:3847/mcp.

Open a local webpage, activate the extension, create Feedback, and ask the agent to list it. See [MCP setup](/docs/mcp-setup) for the public tools. No old state is imported or deleted.

## Read locally and verify

Run pnpm dev:web and open http://localhost:3000/docs. Build with pnpm build:web and check types with pnpm --filter pinvelto-docs typecheck.

For isolated automation, use a temporary installation prefix, PINVELTO_HOME, and PINVELTO_PORT; never use an active user service or agent configuration. The production extension expects 3847. The browser acceptance harness supplies its own controlled test endpoint.
