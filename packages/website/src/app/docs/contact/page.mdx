# Project support

Report reproduction steps, observed/expected behavior, package versions, and the reviewed Git commit in [project issues](https://github.com/luxi78/vibe-annotations/issues). Add relevant logs or screenshots after removing private content.

Contributions and upstream adoption follow [the contribution guide](https://github.com/luxi78/vibe-annotations/blob/issue/23/CONTRIBUTING.md). Upstream is a read source, not this project's support destination.
