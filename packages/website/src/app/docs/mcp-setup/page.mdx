# MCP setup

Start the locally installed service and configure a fresh **pinvelto** entry. The server identifies itself as **pinvelto** and exposes only the seven Pinvelto tools below.

~~~sh
pinvelto init --agent codex --non-interactive
pinvelto status
~~~

Init preserves other agent entries. It does not remove upstream configuration. For project scope, use --project with a supported agent. For configuration without startup, use --skip-server. Reconnect your agent after setup.

The default HTTP URL is **http://127.0.0.1:3847/mcp**. SSE clients may use /sse. For manual Codex configuration:

~~~toml
[mcp_servers.pinvelto]
url = "http://127.0.0.1:3847/mcp"
~~~

For clients using JSON MCP configuration:

~~~json
{"mcpServers":{"pinvelto":{"url":"http://127.0.0.1:3847/mcp"}}}
~~~

## Tools and workflow

| Tool | Purpose |
| --- | --- |
| pinvelto_list_feedback | Read Feedback for the intended project/page scope |
| pinvelto_get_project_context | Read project context and instructions |
| pinvelto_get_screenshot | Retrieve image context for Feedback |
| pinvelto_watch_feedback | Wait for new Feedback |
| pinvelto_delete_feedback | Remove completed ordinary Feedback |
| pinvelto_delete_project_feedback | Remove Feedback in the requested project scope |
| pinvelto_update_feedback | Advance Variants lifecycle state |

Ask the agent to read Feedback for your project's URL. Inspect screenshots where relevant, apply the source change, verify it, and remove completed ordinary Feedback. Variants use their [specific lifecycle](/docs/workflows/variants); update_feedback is not a general comment editor. Old tool aliases are absent.
