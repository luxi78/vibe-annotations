# Pinvelto documentation

Pinvelto lets you place Feedback on a webpage and pass relevant context to a coding agent. Install the extension and local service from a reviewed revision of this repository. Distribution is internal; there is no browser-store or public package installation step.

## Start here

1. [Build and load the extension, then install the service](/docs/installation).
2. [Connect an agent using the pinvelto MCP entry](/docs/mcp-setup).
3. [Create Feedback and review its progress](/docs/workflows).

The extension supports comments, design previews, screenshots, reference images, and Variants. Copy Feedback without a service, or use MCP to let an agent read and act on it.

## Find the right guide

- [Design previews](/docs/workflows/design-edits) change the visible page before an agent changes project code.
- [Screenshots and images](/docs/workflows/screenshots) cover capture permissions and attachment availability.
- [Exports and import](/docs/workflows/sharing) explain which formats carry images.
- [Variants](/docs/workflows/variants) cover generation, choosing, finalization, and discarded-code cleanup.
- [Troubleshooting](/docs/troubleshooting) covers connection and installation failures.
- [Local updates](/docs/releases) use an explicitly reviewed revision.

Run pnpm dev:web and open http://localhost:3000/docs. No hosted deployment is required. Project changes and reports belong in [this repository](https://github.com/luxi78/vibe-annotations).
