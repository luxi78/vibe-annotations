# Architecture

The WXT-built extension injects a toolbar and shadow-root UI into enabled pages. Feedback, settings, bridges, and cross-frame inspection sessions use independent Pinvelto identities. The page bridge is window.__pinvelto.

The local pinvelto-server package supplies the pinvelto executable, HTTP service, and MCP interface at 127.0.0.1:3847. Health includes Pinvelto identity; another healthy service is not accepted as this product.

Feedback transport retains /api/annotations internally. This neutral transport shape is not an old command/tool alias. State is independent under ~/.pinvelto: annotations.json, attachments, and port-specific lifecycle records. Upstream state is not read or migrated.

The CLI verifies the service and its launch record before lifecycle operations. Stop sends an authenticated request to the owning instance, not a signal to a stale PID. The Next.js documentation site runs locally and is unnecessary for browser-to-MCP operation.
