# Variants

Variants let an agent generate alternatives in the actual project, preview them in the browser, and finalize a choice. A local service and connected coding agent are required.

1. Select a component, open Variants, and describe alternatives. Ordinary Feedback explicitly requesting alternatives also yields generation guidance.
2. The agent reads Pinvelto instructions, implements preview/selection scaffolding in the project, and marks the request variants-ready using pinvelto_update_feedback.
3. Preview alternatives and choose one. The request becomes variant-chosen.
4. The agent reads the choice, inlines the winning source, removes temporary scaffolding, and finalizes through pinvelto_update_feedback. Verify the project result.

## Discard and cleanup

Discarding generated Variants marks metadata for agent cleanup. The agent removes Pinvelto-generated temporary artifacts, restores the intended project state, and completes the discarded lifecycle. Ordinary Feedback deletion and global Feedback deletion do not authorize deleting generated project code.

Only new Pinvelto markers and page integrations are recognized. Upstream-generated Variants artifacts are neither migrated nor cleaned. Review the source diff and run the project's normal checks after finalization or discard; a visible preview alone is not proof of correct source work.
