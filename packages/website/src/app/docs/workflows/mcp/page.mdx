# Feedback through MCP

Start the local service and connect through the pinvelto entry. Ask your agent to list Feedback for the intended project URL, read images where relevant, implement changes, verify, and remove completed ordinary Feedback. The extension reflects those actions.

Across pages, use View all's site/page filters to control review scope. The toolbar count stays global. [MCP setup](/docs/mcp-setup) describes all seven tools and Variants-specific update behavior.
