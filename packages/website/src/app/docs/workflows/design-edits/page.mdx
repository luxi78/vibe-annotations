# Design previews

Select an element in inspection mode and open Design. Change supported colors, spacing, typography, layout, or alignment to preview the result directly in the page. The alignment matrix follows the selected layout direction.

Save Feedback and ask your agent to implement the design in project source. A design preview is temporary page state, not a source edit. Review it in context, then test the implemented change normally. Reset controls or delete the relevant ordinary Feedback to remove its preview without clearing unrelated Feedback.
