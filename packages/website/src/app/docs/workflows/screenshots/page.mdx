# Screenshots and images

Feedback can include an element screenshot and reference images. Grant the extension relevant page/capture permission when prompted. Capture uses the actual browser page; check that the intended element is visible and unoccluded.

The local service stores new images under ~/.pinvelto/attachments. An agent reads attachment metadata and retrieves visual context with pinvelto_get_screenshot. If the service is unavailable, local creation can remain usable but image synchronization must complete before the agent reads bytes.

A thumbnail represents an attachment, not a separate record. Replacing an element capture preserves unrelated reference images. Deleting Feedback removes its attachment records through the normal synchronization path.

HTML exports embed available image bytes. JSON and Markdown do not carry separate reference-image files to another machine. Reattach missing files after import; an imported path does not prove an image exists. See [Exports and import](/docs/workflows/sharing).
