# Feedback and review

Open a local webpage with the extension enabled. Click the pencil or configured inspection shortcut, select an element, and write Feedback. Use Design controls for a visual preview or attach image context. Save, then Copy or ask a connected coding agent to read it through MCP.

## Review scope

**Current site** is the tab's website. **Selected site** is the website you choose in View all and may differ from the current site. **All** shows unresolved Feedback across the selected site's pages. **This page** filters to the current tab's full URL; selecting another site can therefore show no matches.

The toolbar count covers unresolved Feedback across **all sites**, independently of the visible list. A refresh keeps the selected site, filter, scroll position, and relevant focus while that View all session remains open.

## Completion and deletion

Agents apply source changes, verify them, and delete completed ordinary Feedback through MCP. Reopening the extension shows the result. Individual and selected-site deletion have their respective scopes. Discarded Variants can retain metadata so the agent can clean generated code.

The separate **global deletion** asks for confirmation and removes only the confirmed Feedback records and attachments, including resolved records. It never removes generated project code. New records added after confirmation are preserved. Use the [Variants lifecycle](/docs/workflows/variants) when code needs finalizing or cleanup.
