# Exports and import

Open View all and choose the site's export format. New exports identify **Pinvelto Feedback**. Finalized Variants are excluded from normal review and export.

| Format | Intended use | Image availability |
| --- | --- | --- |
| Markdown | Readable summary or agent handoff; works without the service | Local references, not transported image bytes |
| HTML | Self-contained review; requires the local service | Available screenshot/reference images embedded; unavailable images omitted |
| JSON | Re-import new Pinvelto Feedback | Metadata and attachment references only; image bytes are not bundled |

The JSON envelope identifies Pinvelto. Import accepts new Pinvelto exports and recreates supported Feedback and previews. Legacy upstream exports are rejected. A reference path from another machine remains unavailable until its image is provided; keep originals or attach images again.

Check HTML in a browser before sharing. Check imported Feedback and attachment availability before handing it to an agent. Ordinary deletion, Variants discard, and global deletion have different effects; see [Feedback and review](/docs/workflows).
