# Pinvelto security reporting

Report concerns to the maintainer of [luxi78/vibe-annotations](https://github.com/luxi78/vibe-annotations). If a private reporting option is available there, use it for sensitive details. Otherwise contact the maintainer through the internal channel used to obtain this installation before posting exploit details publicly; no separate security mailbox or response-time commitment is assumed.

Include the reviewed commit, package/browser versions, affected boundary, configuration, reproduction steps, impact, and sanitized evidence. Never include private Feedback or project source in a public report.

Use only the maintainer-reviewed internal revision and deliberate local update procedure in README.md. Keep the service bound to loopback and do not expose it publicly. Review extension site/capture permissions. Feedback and images persist locally but intentional export/sharing can disclose them; inspect files before sharing. Keep upstream installation state and configuration untouched.
